# Emanuel

Software developer based in Italy. Since 2023 I've been writing C# / .NET software for industrial gas-analysis instruments: the touchscreen HMIs on the machines, the services behind them and the tools around them.

## Work

- I build desktop HMIs with Avalonia and WPF (MVVM, ReactiveUI) that run on Windows PCs and on Linux ARM boards.
- I worked on moving HMI/SCADA products from Windows CE to Linux ARM (Debian, systemd).
- I write the communication layer with the analyzers over Modbus TCP and RS485.
- I write ASP.NET Core REST APIs and store high-frequency measurements in PostgreSQL and SQLite.
- I handle software licensing with ECDSA signatures and generate PDF reports from HTML.

## Side projects

**Krypta**: end-to-end encrypted chat rooms, with an Avalonia desktop client and an ASP.NET Core server over WebSocket. The server runs on an Orange Pi for now; a public demo server is planned. The cryptography has not been independently audited.

**Oscilloscope Viewer**: opens oscilloscope CSV exports in the browser, including files with several captures of different channel counts. Parsing streams through a Web Worker, so large files never sit in memory as text. It has cursors, automatic measurements, FFT and math channels, and ships as a single HTML file that works offline.

## Currently learning

- ReactiveUI in depth, working through *You, I, and ReactiveUI*

C# · .NET 8 · Avalonia · WPF · ReactiveUI · ASP.NET Core · PostgreSQL · SQLite · Modbus · Linux (Debian, systemd) · NGINX · Bash · HTML / CSS / JS
